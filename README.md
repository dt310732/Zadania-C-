# Podstawy programowania C++ - zadania i ćwiczenia

Wszystkie zadania są na stronie [Zadania](https://piskorowskijakub.pl/course/Programowanie-w-C++/)

Repozytorium zawiera rozwiązania zadań z kursu **„Podstawy programowania C++”**. Każdy folder odpowiada osobnemu tematowi i zawiera programy napisane w języku C++.

## Struktura repozytorium

- `zad1` - pierwszy program
- `zad2` - if
- `zad3` - switch
- `zad4` - pętle while i do-while
- `zad5` - for
- `zad6` - zmienne tablicowe
- `zad7` - tablice znakowe i obiekty string
- `zad8` - funkcje
- `zad9` - rekurencja, przeciążenia
- `zad10` - wskaźniki
## Opis zawartości

- **zad1-zad5** - podstawy języka C++: wejście/wyjście, instrukcje warunkowe, pętle
- **zad6-zad7** - tablice i operacje na danych
- **zad8** - funkcje i ich zastosowanie
- **zad9** - rekurencja oraz przeciążanie funkcji

## Wymagania

- Kompilator C++, np. `g++`, MinGW lub clang
- System Windows, Linux albo macOS

## Jak uruchomić program

### 1. Sklonuj repozytorium

```bash
git clone https://github.com/dt310732/Zadania_cpp.git
```

### 2. Przejdź do folderu projektu

```bash
cd Zadania_cpp
```

### 3. Przejdź do wybranego zadania

Przykład:

```bash
cd zad8
```

Jeżeli folder ma nazwę z nawiasami, np. `zad8(funkcje)`, użyj:

```bash
cd "zad8(funkcje)"
```

### 4. Skompiluj plik

```bash
g++ nazwa_pliku.cpp -o program
```

Przykład:

```bash
g++ main.cpp -o program
```

### 5. Uruchom program

Windows:

```bash
program.exe
```

Linux / macOS:

```bash
./program
```
